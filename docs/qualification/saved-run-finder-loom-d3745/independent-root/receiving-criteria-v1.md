# TestPilot saved-run history — independent receiving criteria

Root's controller and Anvil's exact 34-case oracle corpus precede root exposure to Loom's candidate. Root has read only the original package/CLI, original producer reports, public contract, and public oracle generator. The receiver will run the ordinary module CLI with Python `-S -B`, no site packages, no inherited credentials, an empty PATH, and only `history` arguments. It will not invoke TestPilot's generation, model, pytest, recheck, or regression commands.

The entire exact case specification is frozen by SHA-256. Expected stdout files are literal bytes; their membership, saved-record summaries, ordering, counts, problems, text layout and JSON layout derive from the public contract. Neither an implementation import nor another scanner generated the expectations. Two source reports are producer-retained Git bodies; all other synthetic records are labelled as such.

Acceptance requires all 34 commands to meet their public exit, exact stdout and exact stderr (or the specified narrow argparse/root error substring), close their owned process group normally without timeout or cleanup, and leave every offered source leaf, control, and input namespace unchanged in bytes, modes, mtimes, identities and links. Each command gets a prospective separate stdout/stderr file. A failed case remains failed; later cases still execute to reveal independent outcomes. The receipt records all failures. Any launch/admission/controller failure stops the course and is retained.

The actual limits are exercised: 1,001 candidate paths, 20,001 directory entries, exact 16MiB files and 16MiB+1, exactly 64MiB accepted bytes and a fifth 16MiB candidate, and per-file admission before the remaining global budget. Hard links make the input corpus economical while remaining distinct candidate paths as the public contract specifies. Internal symlinks are skipped; the selected root symlink resolves; a static FIFO must return without being opened for its body. A hung owned process is terminated only in its own process group and makes receiving fail.

Other cases cover native and authored recheck summaries, source-schema kind rather than filename, depth zero/default/two, repeated-status OR with kind/query AND, Unicode casefolding, literal brackets, empty filters, no-match success, invalid unselected neighbors, BOM, malformed JSON, duplicate keys, nonfinite values, a boolean where an integer is required, and invalid roots/options. A valid JSON non-object is an invalid native core (`invalid_report`), as resolved publicly before candidate exposure.

This course observes the real CLI and owned filesystem. It does not claim an OS-wide network or process audit, hostile-path protection, concurrent-writer atomic snapshots, authentication of historical claims, renewed execution of retained tests, installed-consumer adoption, or coverage of every API validation branch. Loom's separate focused and optimized API evidence remains separate. Root will review the offered source fence after controls freeze, then execute this one independently designed course.

The 25-second per-command timeout is a deadlock bound, not a performance requirement. Normal CLI commands are sequential to avoid fixture or evidence contention. No scheduled continuation or background service is created.
