maintained `docs/HISTORY.md` for usage, record meanings, partial results and
limits. This evidence records one new five-path implementation of the existing
issue 39 contract; the original source-integration credit is retained.

that a buffered descriptor wrapper could read ahead internally. V2 changes only
that wrapper to `os.fdopen(..., "rb", buffering=0)`. The original V1 source freeze,
21-method normal result and six optimized results remain unchanged. The original
V1 `history.py` is retained as `received-v1/history.py` under this author evidence
directory. The final maintained source is the V2 body, not that historical copy.

The separate V2 course ran four existing byte-boundary and changed-size controls
and observed five actual descriptor opens with `buffering=0`. All four passed;
the exact one-line patch, raw streams, both source inventories and final freeze

`../independent-root/README.md` and the raw independent receipt; the independent
corpus generator and compressed exact original case specification preserve that

Forge independently read all five final source/test/guide files, authenticated
the original bindings and additive diffs, and accepted the final source without

## Reproduce the focused checks

From the complete source checkout with Python 3.12+:

```sh
python -B -m unittest discover -s tests -p test_history.py -v
python -B -m testpilot history --root eval/results --json
```

The first command's tests use disposable directories. The second only reads the
repository's retained eval reports. A different checkout may contain additional
records or malformed neighbors; inspect its `complete`, counts and problems.
Saved report statuses remain historical claims, not new test verification.

Original refusal, source freeze, full before/after identities, raw stdout/stderr
and exact author command strings are retained separately. Their historical
paths and unpublished-at-execution state are not rewritten at publication.
